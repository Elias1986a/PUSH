## New

- **Lay out text by voice.** Say "new line" or "new paragraph" where you pause and PUSH breaks the line. Say "bullet point" before each item for a bulleted list.
- **Numbered lists.** "Number one, milk. Number two, eggs." pastes as `1. Milk` and `2. Eggs` on their own lines. It only becomes a list when the numbers count up from one, so "we're number one" stays a sentence.
- **Rank your microphones** (Settings ▸ Dictation). Add the mics you use in the order you prefer; PUSH records from the first one that's connected, and switches as soon as you plug one in.
- **Closed-lid mode.** With your MacBook's lid shut, PUSH skips the built-in microphone, which records silence when the lid is closed, and uses a real one instead.
- **What's new, right here.** Update notes now show in this window, with the last few versions below.

## Changed

- The single microphone choice is now a list. If you had picked one, add it again in Settings ▸ Dictation.
