## New

- **PUSHTYPE is for sale.** A license covers up to three Macs, and you can add more later.  Enter your key in Settings ▸ License, or when setup asks for it.  Talk and TYPE need a license to run.
- **Works offline.** Your license is checked with our store when you're online.  Without the internet, PUSHTYPE keeps working for 30 days before it asks to check again.
- **The app is now called PUSHTYPE.app.** New downloads use the new name.  If you update from an earlier version, your copy keeps its old name and works the same.

## Better

- **Rewriting is gone.** The experimental model that rewrote what you said made every dictation slower, so we removed it.  If you downloaded it, PUSHTYPE deletes the 1.1 GB file for you.  Punctuation still comes from the fast punctuation model.
